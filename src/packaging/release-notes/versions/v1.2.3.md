- **New: videos (experimental).** Attach a video and ask about it. HyperFlux
  takes 2 to 6 still frames with Windows' own video decoder (nothing to install)
  and shows them to your model, or, if it can't see, passes it notes on each
  frame. It doesn't see the movement between frames or hear the sound, and it can
  take a few minutes on a modest PC.
- **Deleting a chat now asks first.** The ✕ next to a chat used to delete it
  straight away.
- **Fixed: the update card covered Settings and Appearance.** In the Modern style
  it now sits on its own row above them, and takes less room.
- **Fixed: the image helper asked to download a vision file you already had.** It
  now also finds a vision file kept next to the model.
- **Faster chat on 4 GB graphics cards.** The picture reader now runs on the
  processor there, so much more of the model fits on the graphics card (22 layers
  instead of 7 in our test with Gemma 4 E4B). Chat is faster; each picture takes
  a few seconds longer. Settings > Model > Pictures or chat speed lets you switch.
- **Conversation memory now sizes the server too.** A smaller memory uses less
  RAM. Changing it reloads the model.
- **Optional: More speed.** Settings > Model > GPU layers can put more of the
  recommended E4B model on a 4 GB NVIDIA card (about 44% faster writing in our
  test). It needs Conversation memory of 8,192 or less, is off by default, and
  goes back to Automatic if the model server stops.
- **No unneeded image helper.** If your model sees pictures itself, the helper
  is no longer loaded.
- **Choose where the image helper runs.** On a PC with integrated graphics,
  Settings > Voice & pictures now lets you run the helper's picture reader on it
  instead of the processor. The processor is recommended and stays the default:
  integrated graphics usually draws your desktop too, so Windows and other apps
  can lag while it works.
- **The image helper looks beside your model.** It no longer offers to download
  the helper model when it sits in the same folder as your main model.
