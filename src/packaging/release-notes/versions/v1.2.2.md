- **Fixed: a stray `</turn>` at the end of answers.** Some models (Granite, Qwen...)
  copy Gemma's end-of-turn marker as `</turn>`. HyperFlux now stops generation
  there, hides it, and removes it from older saved chats so the model doesn't
  copy it again.
- **Search triggers less often.** Messages that talk about the chat, the model
  you're using or yourself ("right now you're Granite, last time Qwen did...")
  no longer start a web search just because they name something. And when
  HyperFlux does search, the model only uses the sources that relate to your
  question, and answers from its own knowledge if none do.
- **Pictures work with any model.** Models that can't see (Granite, Qwen...) now
  get your picture's text through Windows' built-in OCR, with no download. Small
  text is enlarged and read again, and receipts and tables keep their rows.
- **Image helper (second server).** In Settings > Voice & pictures you can turn on
  a small Gemma 4 E2B server that describes pictures for the main model: ask what
  is in the background and it looks, with your question in mind. It runs on the
  CPU, starts only when a picture needs it, and sleeps after 10 idle minutes.
  While it's on, both servers show in the top bar. It needs 8 GB of RAM or more.
- **Questions go to the right reader.** Text questions go straight to OCR and
  questions about the scene go straight to the helper. If neither is available,
  HyperFlux says so immediately instead of making you wait.
- **Fixed: Qwen stopping at the start of code.** HyperFlux sent every model
  Gemma's turn markers, and Qwen copied one (`<|turn>`) while starting an HTML
  page, which ended its answer. Qwen now gets its own ChatML format and Granite
  its own role format, other models get stop words that only match a real new
  turn, and stray markers are hidden from the answer.
- **New recommended E4B: Unsloth dynamic Q4_K_XL.** Setup's optional higher-quality
  choice is now Gemma 4 E4B in Unsloth's dynamic Q4_K_XL quantisation (5.1 GB).
  When HyperFlux runs that file it answers at temperature 0.5 on its own, unless
  you have set your own temperature; Settings says so. Earlier E4B downloads keep
  working.
