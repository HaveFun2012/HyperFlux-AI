- **Show HyperFlux a picture.** Attach a photo or screenshot with the paperclip
  and ask about it, including follow-up questions. Crop it before sending to
  make small text readable; if HyperFlux can't read something, it says so
  instead of guessing. Turn it on once in **Settings → Image input** (a one-time
  download of about 1 GB).
- **Read aloud.** Every answer has a **Read aloud** button that uses your Windows
  voices. Pick the voice in Settings.
- **Custom instructions.** Tell HyperFlux about yourself once, in Settings, and
  it remembers it in every chat.
- **Personas.** Tutor, Coder, Concise or Friendly, in Settings or with
  `/persona`.
- **Search your chats** from the box above Recent Chats.
- **Export a chat** as a Markdown file with the download icon, or type `/export`.
- **Command menu.** Type `/` to see every command as you type.
- **Clearer answers.** Apex 1 answers in its first sentence and matches the
  length to the question. Thinking is now off by default for faster replies;
  riddles still think, and Horizon 1 always does.
- **Friendlier updates.** HyperFlux asks before updating and shows what
  changed. Choose **Later** and the update waits in the sidebar.
- In the terminal app: `/persona`, `/instructions` and `/export`.
